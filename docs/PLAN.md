# Layout 전극 분리 저장소 계획

상태: 사용자 요구를 반영한 설계안 및 합성 추출 실험 완료. 새 저장소와 제품용 엔진은 아직 생성하지 않음.

## 확정된 요구

- 입력은 공통 ROI 좌표를 사용하는 layer별 이미지이며 해상도는 0.1 µm/px,
  대표 크기는 500–700 px이다.
- ROI는 상하좌우로 동일하게 반복되는 unit pixel이다.
- TR은 GAT와 ACTIVE 또는 OACTIVE의 겹침에서 추출한다. 한 TR 위치에
  여러 GAT가 중첩되는 경우는 없다.
- 추출한 TR 영역은 **모든 layer 이미지에서 제거**한 후 연결성을 판단한다.
- CNT/VIA와 stack 연결 규칙으로 연결되는 layer별 segment를 하나의 출력 전극으로 묶는다.
- 반복 구조는 ROI 경계에서 잘린 조각의 연결을 판정하는 데 사용한다.
  최신 요구에 따라 출력은 원본 unit의 2×2 영역이다. 해상도는 유지하고 ROI 폭·높이를 각각 2배로 기록한다.
- TR명과 전극명은 사람이 지정한다. 회로도 이미지를 이용한 이름 제안을 후속 지원하며,
  필요하면 회로 netlist 입력으로 확장한다.
- 출력은 전극별 폴더 안의 layer별 이미지와 TR 폴더이다.

## 데이터 계약

입력 manifest는 layer ID, 이미지 경로, 역할(GAT/ACTIVE/OACTIVE/도체/CNT/VIA/기타),
좌표·해상도, TR 검출 layer 조합, stack 및 contact 연결 규칙을 포함한다.
원본 입력의 이진 여부와 파일 형식은 실제 샘플로 확인한다. 컬러나 회색조라면
명시적인 변환 규칙을 별도 입력 단계로 둔다. 연결 엔진은 검증된 이진 마스크만 받는다.

stack의 높이·순서와 CNT/VIA 연결 정의는 구분한다. 각 hole layer가 연결하는
도체 layer를 명시하거나 stack에서 유일하게 도출하여 검증해야 한다.
모호한 연결을 단순히 가장 가까운 layer로 확정하지 않는다.

원본 마스크, TR 제거 마스크, 최종 전극 마스크는 서로 분리해 보관한다.
추출 ID와 사용자가 지정한 이름도 구분하며 파일 경로로 사용할 수 없는 이름은
표시 이름을 보존한 채 안전한 폴더명으로 변환한다. 이름 충돌을 검사한다.

## 추출 과정

1. 모든 이미지의 크기, 좌표, 해상도, 이진 값과 layer 역할을 검증한다.
2. 지정된 각 GAT–ACTIVE/OACTIVE 조합의 교집합을 계산한다.
   원인이 된 layer 조합을 보존하며 TR 후보에 ID를 부여한다.
3. 전체 TR 마스크의 합집합 T를 만들고 모든 layer에 L_after = L_original AND NOT T를 적용한다.
   CNT/VIA 이미지에도 동일한 제거 규칙을 적용한다.
4. 남은 도체 영역의 layer별 연결 성분을 segment로 추출한다.
   CNT/VIA는 연결을 판정하는 mask이며 도체라는 이유 없이 같은 평면 전극으로 취급하지 않는다.
5. stack 규칙에 따라 남은 contact hole과 실제로 접촉하는 segment 사이에 연결을 만든다.
   연결 대상 누락·복수 접촉은 검사 결과와 원인을 보존한다.
6. 반복 경계를 넘는 연결을 포함해 기준 ROI의 segment를 전극으로 그룹화한다.
7. TR 주변의 제거 전후 정보를 이용해 TR–전극 관계를 기록한다.
   전극을 TR을 통해 자동으로 합치지 않는다.
8. 사람이 TR 후보의 이름·필요한 그룹과 전극명을 지정하고 결과를 내보낸다.

대각선 한 점 접촉을 연결로 볼지(4/8 연결), contact 최소 겹침 기준,
인접한 TR 후보를 하나의 TR로 묶는 규칙은 설정과 샘플 정답으로 확정한다.
자동 팽창·침식으로 1 px 연결 또는 단절을 임의로 고치지 않는다.

## 반복 경계 판정

단순 3×3 타일은 검토용 그림과 작은 시험 사례에 사용한다.
3×3 외곽에 닿았다는 이유만으로 완전한 연결성 판정이라고 선언하지 않는다.

연결 그래프의 노드는 layer별 segment이며, 경계 연결에는 이웃 타일로의 이동량
(dx, dy)을 붙인다. 실제 노드의 의미는 (segment ID, tile_x, tile_y)이다.
hole과 TR 후보가 경계에서 잘리는 경우도 같은 좌표 규칙으로 처리한다.

평가할 같은 타일 내 A와 B를 같은 전극으로 묶는 조건은 (A, 0, 0)에서 (B, 0, 0)으로
가는 경로가 존재하는 것이다. (A, 0, 0)에서 (B, 1, 0)으로 연결된다는 사실만으로
기준 ROI의 A와 B를 합치지 않는다. 반복 복사본의 형상이 같다는 이유로 ID를 접으면
서로 독립된 유닛 전극이 잘못 합쳐질 수 있다.

구현은 이동량을 보존하는 주기 그래프로 구성하고, 경로 이동량과 순환 경로에서
가능한 이동량을 이용해 동일 타일 복귀 가능성을 판정하는 방식을 우선 검토한다.
유한 타일 확장만 구현하는 중간 단계에서는 범위 밖 연결을 미확정으로 표시한다.
고정 타일 수나 연속 두 번의 결과 일치만으로 정답을 보증하지 않는다.

출력 전극의 layer별 마스크는 2×2 평가 영역 안에서 해당 그룹의 segment를 OR한 것이다.
원본 unit을 정수배 복제하고 리사이즈하지 않는다. 평가 영역 밖의 연결은 메타데이터에 기록한다.
단일 unit에서 구한 전극 마스크를 각각 2×2 복사하면 독립된 반복 전극까지 같은 ID에
들어갈 수 있으므로, 확장된 layer 이미지에 대해 연결 판정과 전극 ID 부여를 수행한다.

## 모든 layer에서 TR을 제거하는 규칙의 영향

GAT도 절단되므로 출력 전극과 회로도의 전기적 net이 항상 일대일이라고 가정하지 않는다.
회로도 이름 대응에 필요한 원래 GAT 접촉·연결 정보는 별도 근거로 보관한다.
이 정보로 TR 제거 후 출력 전극을 재결합하지 않는다.
하나의 회로 net에 여러 출력 전극이 대응하는 경우를 데이터 모델에서 허용하고,
동일 이름 사용이나 구간별 이름은 사용자 지정으로 처리한다.

## 이름 지정 및 회로도 연동

첫 버전은 로컬 검토 화면에서 layer 표시 전환, 전극 전체 강조, TR 선택,
이름 입력, 미지정 목록과 저장 기능을 제공하는 방향을 제안한다.
수동 지정 결과는 추출 데이터와 분리된 annotations 파일에 저장한다.
입력·규칙 변경으로 대응이 달라진 이름은 재확인 대상으로 표시한다.

후속 회로도 입력은 이미지와 netlist를 같은 회로 연결표로 변환한다.
이미지 입력에서는 OCR뿐 아니라 TR 기호, 배선, 교차점·접속점을 해석하고
사람이 연결표를 수정할 수 있어야 한다. 명명된 전극/TR 일부를 기준점으로 받아
layout의 연결 관계와 회로 연결표를 비교한다.
대칭 회로, 반복 소자, 불명확한 S/D, 이미지 판독 오류는 자동 확정을 막고 후보를 제시한다.
자동 이름은 추출 구조를 변경하지 않으며 사용자 확정 여부와 근거를 기록한다.

## 출력 예시

```text
output/
  electrodes/
    E001__VDD/
      GAT1.png
      METAL1.png
    E002__NODE_A/
      ACTIVE.png
      METAL1.png
  tr/
    TR001__T1/
      mask.png
      metadata.json
  manifest.json
  annotations.json
  connectivity.json
  review/
    overlay.png
    issues.json
```

모든 계산용 PNG는 2×2 ROI 크기의 단일 채널 0/255 이미지이다.
빈 layer 파일은 생략하고 manifest에 포함 layer를 기록한다.
TR mask의 정확한 의미는 GAT–ACTIVE/OACTIVE 교집합이며 TR을 감싼 사각형이 아니다.
TR별 mask, 전체 TR 합집합, 제거에 사용된 규칙을 추적할 수 있게 한다.
미지정 이름은 내부 ID로 임시 저장하고 최종 명명 완료 여부를 명시한다.

## particle-sim 연동

- 출력 전극의 각 layer mask를 별도 electrode_id로 등록한다.
- 하나의 출력 전극에 속한 layer들은 같은 net_id를 사용한다.
- 모든 mask는 원래 layer mask의 부분집합이며 같은 layer 내 전극끼리 겹치지 않아야 한다.
- TR 제거 전 원본 layer mask는 topography 입력으로 보존한다.
- TR 제거 후 contact mask를 내보낼 경우 원본 contact와 구분해 변환 이력을 남긴다.
- 현재 particle-sim의 contact당 아래/위 전극 각 1개 제약과 다중 접촉 결과를 대조한다.
  허용되지 않는 구조는 자동 연결을 숨기지 않고 연동 불가 사유로 보고한다.
- 두께·공정·평가 pair 등 시뮬레이터 필수 설정은 별도 제공받아야 완전한 manifest가 된다.

## 구현 순서와 완료 기준

1. 실제 샘플 및 정답 계약
   - layer 역할, TR 검출 조합, stack 연결 규칙과 작은 수작업 정답을 확보한다.
   - 경계 너머에서 연결되는 조각과 독립된 이웃 복사본을 반드시 포함한다.
2. 추출 엔진
   - TR 검출, 모든 layer에서 제거, segment 추출, CNT/VIA 연결을 구현한다.
   - 사람이 지정한 정답의 TR 픽셀과 전극 그룹에 일치해야 한다.
3. 반복 경계 연결
   - 이동량을 보존한 연결 판정을 구현한다.
   - 수평/수직/모서리, 여러 tile을 경유하는 복귀, 끝없이 이어지는 배선,
     서로 다른 반복 복사본, 경계 TR/CNT/VIA 사례를 검증한다.
4. 검토 화면과 출력
   - 이름 지정·재로딩·수정, 전극별 layer 저장과 TR 저장을 구현한다.
   - 2×2 ROI와 픽셀 해상도 보존, 중복 없음, 잔여 도체의 미분류 없음,
     이름·내부 ID 참조 무결성을 검증한다.
5. 시뮬레이터 adapter
   - 완전한 fixture 설정과 함께 particle-sim validate-input을 통과한다.
   - 추출 전극 구조와 현재 contact 제약이 맞지 않는 사례는 명확히 보고한다.
6. 회로도 이름 제안
   - 먼저 수동 확인 가능한 회로 연결표/netlist 입력을 지원한다.
   - 그 후 이미지 해석을 연결하고 이름 제안의 정확도·미확정 사례를 실제 샘플로 평가한다.

## 2×2 계산 계약

- 600×600 px, 0.1 µm/px unit은 60×60 µm이며 출력은 1200×1200 px, 120×120 µm이다.
- ROI 면적은 3600에서 14400 µm²로 바뀐다. mask, contact, terminal, ROI 메타데이터를 모두 일치시킨다.
- raw CA는 면적과 경계·전극 구성에 영향을 받는다. 2×2 raw CA가 항상 unit의 정확히 4배라고 가정하지 않는다.
- 단위 면적 CA 비교는 실제 평가 면적을 분모로 사용한다. 확률 map 값 자체를 4로 나누지 않는다.
- 연결 판정을 위한 주변 영역과 이물 평가 영역은 구분한다. 2×2 바깥 경계 효과는 여전히 남는다.
- 현재 particle-sim은 주기 경계를 자동 처리하지 않는다. 특히 ROI 경계를 open 단자로 쓰는 정책은
  반복 배선의 인공 경계를 단자로 볼 수 있으므로 별도 검증이 필요하다.
- 배열 크기는 unit의 4배이나 전극 수와 평가 조합도 달라져 전체 계산 비용은 4배를 넘을 수 있다.

## 수행한 합성 실험

- 스크립트: outputs/layout-electrode-prototype/build_fixture.py (재생성 가능한 로컬 실험 산출물).
- 폭 20 px = 2 µm, unit 600×600 px. 굴곡·분기·루프·독립 섬·수평/수직 경계 배선을 포함한다.
- GAT1/GAT2, ACTIVE/OACTIVE, CNT1/CNT2와 연결용 METAL1을 사용한다.
- 임의 연결 규칙은 CNT1: ACTIVE–METAL1, CNT2: OACTIVE–METAL1이다.
  실제 공정을 재현한 stack이나 물리 시뮬레이션 manifest가 아니다.
- 4×4 확장 영역에서 연결을 추출해 중앙 2×2를 저장했다. 6×6 확장에서도 동일한 분할을 확인했다.
- 결과: 2×2에서 TR 8개, 전극 25개. CNT 연결, TR 단절, 경계 배선 연결,
  독립 섬 4개의 분리, 잔여 도체 픽셀 보존 검사를 통과했다.
- 유한 확장 비교는 이 fixture의 검사이며 임의 반복 구조의 정확성 증명이 아니다.
- 실제 이물 시뮬레이션과 회로도 이름 매칭은 아직 수행하지 않았다.

## 실제 입력 연동 시 필요한 자료

- 실제 layer 이미지 한 세트와 layer 역할 목록.
- CNT/VIA 연결 대상이 포함되거나 유일하게 도출 가능한 stack 예시.
- 대응 회로도 이미지와 알려진 TR/전극 몇 개의 이름 또는 수작업 정답.
