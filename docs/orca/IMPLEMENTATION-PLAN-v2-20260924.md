## 입력·실패 계약

- Extractor 기존 extraction schema/CLI는 유지한다. `export-particle-sim`에 `--config <JSON>`만 선택적으로 추가한다. **모드 표:** (a) 설정 없음 = 현행 legacy: 단일 endpoint pair/물리 mask만 허용, mixed CNT1은 출력 전 거부, 입경 `[1.0]`, 합성 가정 stack·`SOURCE_AFTER_TOP_CONDUCTOR` 유지. (b) `profile="synthetic"` 설정 = mixed CNT1 분할 허용, 확정 32 지름을 emit, 가정 stack과 단계 의미를 manifest 옆 provenance에 기록. (c) `profile="measured"` = 명시 공정/단계/물성/net 입력 검증, 누락 시 출력 전 실패; 현재 CNT 개구 물리 의미를 simulator가 표현하지 못하므로 그 stage가 요구되면 명시 미지원/거부. 어떤 모드도 실제 물성/확률 가중치를 꾸미지 않는다.
- **P0/P1 최소 config JSON 계약:** `schema_version: 1`, `profile: synthetic|measured`, `process_stack: [{id,kind: conductor|hole|dielectric,mask_layer: id|null,material_type: conductor|inorganic|organic,thickness_um: positive number,patterned: bool,planarization_factor?: 0..1}]`, `source_stages: [{step_id,after_layer,semantics,surface_model,fab_distribution_layer}]`, `contact_applicable_stages: {CNT1:[step_id],CNT2:[step_id]}`, `particle_sizes_um`. P2에서 `net_map?: {extracted_electrode_id: circuit_net_id}` 및 명시 pair/open-path/`cno_open_relations`를 추가한다. P0/P1은 이 P2 필드가 아직 없으면 합성 임시 net과 전수 pair·open 미설정 상태를 유지한다. `id`, `step_id`, `mask_layer`는 안전한 고유 ID이며 두께 단위는 µm, 숫자는 유한·양수, ID/row/stage는 중복 불가, 필수 필드 누락과 미지 extra 필드는 오류다. `source_stages.semantics`는 `after_pattern` 또는 `cnt_open_before_fill_approximation`으로 제한하고, `surface_model`은 simulator가 지원하는 값만 허용한다. masked projection은 extractor `physical_stack`과 순서·ID가 같고 conductor projection은 `stack`과 같다. hole row는 mask ID를 가리키되 simulator의 non-patterned inorganic row로 변환하고, conductor row는 patterned conductor 및 raw topography `layer_mask`를 가진다. 무마스크 dielectric은 `mask_layer=null`, `patterned=false`, simulator stack row만 있고 source stage는 **0개**다. `after_layer`는 실제 stack row ID여야 하고 mask-bearing row만 가리킬 수 있다. source stage는 mask-bearing 층 중 명시된 부분집합만 만들되 중복·순서 역전·없는 마스크는 거부한다. simulator 필수 필드와 명시 값의 변환은 sidecar에 기록한다. P0 Task가 8개 mask 층과 최소 1개 무마스크 ILD를 담은 가정값 표시 synthetic config 예시를 함께 낸다.
- **CNT stage 의미와 contact 적용:** 현재 simulator는 CNT row를 평막으로만 보고 `lands_after_layer=CNT`를 열린 홀·충전 전 표면으로 표현하지 못한다. synthetic 설정에서는 CNT1/CNT2 stage를 emit하되 `surface_semantics="flat_film_approximation_unsupported"`를 provenance에 표시하며 각 contact row의 적용 단계는 **그 CNT stage만** 넣어 schema의 비어 있지 않은 목록 조건을 충족한다. 이 결과는 API/기하 기능 시험이고 물리 CNO 검증이 아니다. measured 설정에서는 CNT 개구 stage 또는 그 contact의 물리 CNO가 요구되면 외부 simulator 공정모델 확장 전까지 출력 전 거부한다. legacy 설정은 이전 적용 단계와 의미를 유지한다.
- 확정 회로 net ID 없이는 추출 ID로 **합성/임시 net**을 만들 수 있지만 확정 short 통계라 주장하지 않는다. 명시 net map에서 다수 추출 전극→한 회로 net을 허용하고 원본 전극 ID/물리 mask는 바꾸지 않는다. 같은 raw GAT TR 양편, ACTIVE/OACTIVE S/D를 자동 병합하지 않는다. pair는 전수 분류 또는 검증 가능한 명시 제외 이유를 남긴다. open-path는 단자·net 근거 없으면 생성하지 않고 `unsupported/unconfigured`라고 보고한다. `open_applicable_steps_by_layer`는 빈 목록으로 두어 ROI 경계를 단자로 쓰는 auto-open을 켜지 않는다.
- Contact export는 물리 CNT1/CNT2 두 mask만 소유한다. 각 raw CNT **4-연결** 성분은 유일한 선언 endpoint pair와 raw→cut provenance를 가져야 한다. extractor가 8-연결을 쓴 경우 4-연결 성분 분할이 픽셀 단위로 동일한 홀 집합인지 검증하고 다르면 출력 전 거부한다. export row는 endpoint pair별 분할 mask, 고유 contact ID, 원래 `hole_layer`를 사용한다. row 간 비중첩, 행 union=cut physical CNT, 빈/누락/중복/잘못된 endpoint/부분 TR 절단/외곽 잘림을 출력 전 진단한다. raw/cut/effective 픽셀 수는 마스크와 `raw_components`/`components`에서 직접 계산해 sidecar에 보존한다. raw 홀 소실도 검출한다. 부분 절단 홀은 조용히 작은 분모로 바꾸지 않고 기본 거부한다. 두 브리지의 graph-edge/두 홀/연속 METAL 근거와 100 CNT 홀/2×2를 검증한다. 기존 raw/cut/TR40/전극 periodic ID는 불변이다. Simulator용 도체 `layer_masks`는 지형용 **raw** 마스크이며, 전극·접점 mask는 TR-cut을 유지한다.
- 확정 지름은 `1..30,40,50` µm **32개만**. CNO는 all-layer TR cut 후 simulation 입력의 **개별 온전한 CNT 홀 연결 성분 전체 픽셀** 중 가림이 `2*covered>=hole_pixels`인 경우다. effective endpoint 면적은 분모가 아니다. raw/cut/effective 픽셀 수는 simulator manifest가 아닌 adapter **sidecar**에 각각 보존한다. 기본 가림 footprint는 **물리 입자 disc, CNO margin=0**이고, 기존 `contact_margin_um`을 CNO에 조용히 더하지 않는다. 다른 CNO 가림 margin은 명시 config와 별도 검토 없이는 허용하지 않는다. Nominal 사건 키는 `(source_step, diameter_um, centre_y, centre_x, particle_shape)`이며 stochastic 확장 때만 `sample_id`를 추가한다. 홀별 raw CNO와 기존 link any-hole OR 결과를 구분해 보존한다. `cno_open_relations`는 CNO 홀/link ID→open path ID의 **명시 관계표**이고 같은 net이라는 사실만으로 생성하지 않는다. 관계가 없는 open은 미분류·원시로 남긴다. 관계가 있는 open의 최종 map은 `open_raw & ~OR(related_CNO)`다. 다른 연결 open과 모든 short, 원시 사건은 남긴다. auto-open은 현재 지원 범위 밖이며 비활성이다.
- 중앙 `[300,900)²` 600px 창만 통계 집계한다. 1200 ROI 각 변 300px halo, 최대 지름 50µm의 반경 250px 뒤 입자 footprint만 50px 여유. 32개 지름 각각 footprint·커널·margin·전체 홀/endpoint/short support를 계산해 여유 초과면 거부 또는 명시 미지원. 회로 open은 비국소 연결이므로 반경 비교만으로 안전 판정하지 않는다. 큰 halo를 만들 때 추출 전극 label을 단순 타일링하지 않고 periodic instance ID를 재계산한다.
